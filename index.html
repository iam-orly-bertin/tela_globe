Install in 4 steps

The app is not on the Play Store yet, so Android asks a few extra questions. It is normal.

  1. Download the APK with the button on this page.
  2. Open the file. If Android blocks it, tap Settings and allow your browser to install unknown apps, then go back.
  3. If Play Protect warns you, tap More details, then Install anyway.
  4. Open Tela Globe, create your account and start.
Is it safe?

Install it only from this page. The warning appears because the app is not from the Play Store yet.

Why is the first opening slow?

The server sleeps when nobody uses it. The first opening can take up to a minute, then it is fast.

Does it work on iPhone?

Not yet. This version is for Android phones only.
